# leomerge

Repositório de experimentos e arquivos de apoio para praticar integração de alterações com Git. Atualmente não contém uma aplicação de runtime nem comandos de execução próprios.

## Stack
- Git e GitHub
- Arquivos de configuração e verificações automatizadas

## Como consultar
Explore o histórico e os arquivos do repositório. Não há comando de inicialização de aplicação configurado.
